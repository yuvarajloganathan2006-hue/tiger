The previous candidate list also included ClawDesk, but its README could not be retrieved during this review. Its current features and license are unverified here.

TIGER uses these repositories as design references. No source code from these projects is copied in the initial scaffold. Before incorporating code, record the exact source version, file paths, copyright notices, license text, modifications, and any attribution or source-disclosure requirements. MIT code may generally be reused with its notices. GPL and AGPL reuse can impose copyleft obligations on a derivative work; obtain appropriate legal review before distribution.
